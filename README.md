# HelpDesk — Backend

API backend de la plateforme HelpDesk intelligente, développée dans le cadre d'un PFE (ISIMA, Université de Monastir, en collaboration avec Sindibad Group).

Frontend : [helpdesk-pfe-frontend](https://github.com/AmnaKrifa/helpdesk-pfe-frontend)

## Stack
- Java 17 / Spring Boot
- Spring Security (JWT)
- PostgreSQL
- Docker

## Fonctionnalités
- Authentification et gestion des rôles (Client, Technicien, Admin)
- Gestion des tickets avec suivi SLA
- Deux agents IA pour l'assistance client et technicien
- Notifications et base de connaissances
